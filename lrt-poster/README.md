# Плакат «Правила безопасности LRT» (не относится к деку KazBioFert)

A4-плакат прокуратуры г. Астаны, 2 слайда: RU (стр. 1) и KZ (стр. 2).

- `source_LRT_ru_kz.pptx` — исходник
- `LRT_safety_poster_FINAL.pptx` — итог
- `build.py` — правки: ЛРТ→LRT (латиница, акцент), дополнение казахского перевода
  под русский, дизайн-полировка (верхняя акцент-полоса, единое скругление карточек).

Воспроизведение: `python3 lrt-poster/build.py`
