# Оценка остаточной стоимости 166 цистерн — методика v2

Компонентный затратный подход к оценке парка из 166 вагонов-цистерн, построенный
на тех же исходных данных, что и первоначальная модель (v1), но с исправленной
методологией.

## Файлы

| Файл | Назначение |
|---|---|
| `Оценка_166_цистерн_v2.xlsx` | Готовая модель v2 (открыть в Excel — пересчитается автоматически) |
| `build_v2.py` | Скрипт-сборщик модели из исходных данных (воспроизводимость) |
| `source/Оценка_166_цистерн_v1_исходник.xlsx` | Исходный файл с данными и моделью v1 |

Пересборка: `cd wagon-valuation && python3 build_v2.py`

## Листы модели v2

- **Комплектация** — исходные данные по вагонам и узлам (без изменений).
- **Справочник** — технические пороги (обод, обточка, цена новой цистерны).
- **Параметры** — допущения методики v2 (доли компонентов, сроки, цены ремонтов).
  Синие ячейки на жёлтой заливке — редактируемые допущения.
- **Прайс** — цены собственника (без НДС) по модели и году постройки.
- **Оценка** — построчный расчёт по 166 вагонам (колонка «Цена продавца»
  подтягивается из листа «Прайс», колонка «Отклонение рынок−модель» —
  разница прайса и оценки по износу).
- **Свод** — итоги, сравнение с ценой собственника и с v1, таблица по группам
  (модель × год), перечень изменений и ограничений.

## Логика расчёта

Остаточная стоимость собирается по компонентам, затем из неё вычитаются денежные
обязательства по предстоящим ремонтам:

```
Компонентная стоимость = Цена новой × (
      доля_котла·остаток_котла
    + доля_литья·остаток_литья
    + доля_КП·остаток_КП
    + доля_прочего·остаток_прочего ) / 100

Итоговая стоимость = Компонентная − Обязательство_ДР(₽) − Обязательство_замены_КП(₽)
```

Остаточные проценты по компонентам:

- **Котёл + рама** — по индивидуальному сроку службы вагона (дата СС из данных),
  а не по общему нормативу 32 года.
- **Тележки (литьё)** — по среднему возрасту боковых рам и надрессорных балок
  (годы из данных) против срока службы литья.
- **Колёсные пары** — среднее по 4 КП; износ обода считается на **полном
  диапазоне** от новой толщины (70 мм) до предела (27 мм).
- **Прочее** — среднее остаточных котла и литья.

Обязательства:

- **ДР** — доля стоимости планового ремонта, пропорциональная использованному
  циклу обслуживания (макс. из цикла по дате ДР и цикла по пробегу).
- **Замена КП** — число колёсных пар, не проходящих обточку (обод после съёма
  15 мм < 35 мм), × стоимость замены одной КП.

## Что изменено против v1

| # | Изменение | Зачем |
|---|---|---|
| 1 | Компонентная декомпозиция (котёл/литьё/КП/прочее) | v1 делил 50-на-50 «вагон vs КП», переоценивая колёсные пары |
| 2 | Индивидуальный срок службы вагона | v1 использовал общий норматив 32 года |
| 3 | Литьё тележек как компонент | v1 годы рам и балок не использовал |
| 4 | Износ обода на полном диапазоне | v1 считал в узкой полосе 50→27, из-за чего 83% вагонов имели 0% износа обода |
| 5 | Пробег как ресурс обслуживания | v1 собранный пробег игнорировал |
| 6 | Стоимость ДР — вычет в ₽ | v1 моделировал ДР как размытую надбавку износа в п.п. |
| 7 | Замена негодных КП — вычет в ₽ | Прямой денежный учёт вместо процентной надбавки |
| 8 | Колонка «Цена продавца» для рыночной сверки | Основа для триангуляции затратный↔рыночный |

## Ограничения (требуют данных / уточнения)

- **Толщина гребня** в источнике не заполнена (= 0). После замера гребень
  следует добавить в износ КП как второй ограничитель обточки.
- **Доли компонентов и цены ремонтов** заданы как допущения на листе
  «Параметры» — заменить фактическими цифрами.
- **Состояние котла** (коррозия, толщина стенки) в данных отсутствует; износ
  тела аппроксимирован сроком службы.
- **Функциональный и внешний износ** (тип цистерны, ставка аренды,
  регуляторные ограничения по возрасту) не учтены — модель отражает
  физический износ.

## Результаты (при текущих допущениях)

- Средняя стоимость v2: ≈ 2,94 млн ₽ (v1: ≈ 3,25 млн ₽, −9,3%).
- Диапазон: ≈ 1,23–3,71 млн ₽.
- Итог по парку v2: ≈ 489 млн ₽.

Разница с v1 объясняется денежным учётом предстоящих ремонтов, добавлением
износа литья тележек и более консервативной оценкой обода.

## Сравнение с ценой собственника

Собственник дал прайс **по модели и году** (одинаковая цена для одинаковых
модель+год, без поправки на состояние). Цены полностью совпали по составу
парка (166 вагонов) и заведены в модель.

| Показатель | Значение |
|---|---|
| Итого прайс собственника (без НДС) | **534,85 млн ₽** |
| Итого оценка v2 (по износу) | 488,77 млн ₽ |
| Переоценка прайса к v2 | **+46,08 млн ₽ (+9,4%)** |
| Итого оценка v1 (справочно) | 538,69 млн ₽ (≈ прайс) |

Прайс собственника — это **линейная лестница по возрасту** (+160 500 ₽ за
каждый год новее для моделей 66–68 тн; блок 2020 г. 69 тн — отдельный тариф
4,125 млн). Состояние вагонов в ней не отражено, поэтому v1 (тоже возрастная)
почти совпадает с прайсом, а v2 (по состоянию) вскрывает расхождения:

| Модель · год | Кол-во | Прайс ед. | v2 ед. | Δ прайс−v2 |
|---|---:|---:|---:|---:|
| 15-1219-1П · 2020 | 60 | 4 125 000 | 3 514 996 | **+15%** |
| 15-150-04П · 2011 | 21 | 2 461 000 | 2 688 740 | −9% |
| 15-150-04П · 2012 | 7 | 2 621 500 | 2 185 309 | +17% |
| 15-150-04П · 2015 | 14 | 3 103 000 | 2 146 025 | **+31%** |
| 15-1755П · 2013 | 24 | 2 782 000 | 2 689 368 | +3% |
| 15-1755П · 2014 | 5 | 2 942 500 | 2 911 097 | +1% |
| 15-5103-7П · 2011 | 23 | 2 461 000 | 2 753 243 | −12% |
| 15-5103-7П · 2012 | 3 | 2 621 500 | 2 878 505 | −10% |
| 15-5103-7П · 2015 | 9 | 3 103 000 | 2 777 964 | +10% |

Переоценены (прайс > стоимости по состоянию): **92 вагона**; привлекательны
(прайс < стоимости): 74. Основной объём переплаты — блок 2020 г. (60 шт),
но по нему сравнение **чувствительно к единой цене новой**: 15-1219-1П (69 тн) —
премиальная модель, при единой цене новой 4,65 млн её v2-оценка занижена,
поэтому реальная переоценка по 2020 г. меньше расчётной. Достовернее сравнение
по моделям 66–68 тн, где предположение о цене новой ближе к факту.
