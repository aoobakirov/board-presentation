# Жаңа айыптау актісінің қазақ тіліне аудармасы

Орыс тіліндегі **жаңа айыптау актісінің** (ЕРДР №247100011000049) қазақ тіліне
заңды-грамматикалық аудармасы. Аударма Қазақстан Республикасының заңнамасында
қолданылатын ресми заң терминологиясына сәйкес орындалды, құжаттың ресми іс
қағаздық стилистикасы сақталды.

## Құжаттың құрылымы

- Кіріспе бөлік және айыпталушылардың тізімі
- Кәсіпорынның (ШЖҚ МКК) сипаттамасы, органдары мен лауазымдық міндеттер
- Айыпталушылардың лауазымдық тарихы мен функционалдық міндеттері
- Қылмыстық схеманың фактілік баяны (екі эпизод: СТО/қосалқы бөлшектер және
  токарлық қызметтер)
- Қылмыстардың саралануы (ҚК-нің 189-бабы)
- Тәркілеу, мүлікке тыйым салу туралы мәліметтер
- Сотталушылар туралы деректер және бұлтартпау шаралары
- Жауаптылықты ауырлататын және жеңілдететін мән-жайлар
- Уәждеу бөлігі (дәлелдемелердің толық тізбесі)
- Процестік шығындар
- Қорғаушы тараптың уәждері
- Қарар бөлігі және қол қою блогы

## Терминология мен қысқартулар

Түпнұсқада берілген қысқартулар аудармада мынадай түрде қолданылды:

| Орысша | Қазақша |
|--------|---------|
| т. (том) | т. (том) |
| л.д. (лист дела) | іс п. (іс парағы) |
| СМП (скорая медицинская помощь) | ЖМЖ (жедел медициналық жәрдем) |
| СТО (сервис/станция техобслуживания) | ТККС (техникалық қызмет көрсету станциясы) |
| ЕРДР | СТЕТ (Сотқа дейінгі тергеп-тексерулердің бірыңғай тізілімі) |
| УК / УК РК | ҚК / ҚР ҚК (Қылмыстық кодекс) |
| УПК | ҚПК (Қылмыстық-процестік кодекс) |
| ст. / ч. / п. / п.п. | бап / бөлік / тармақ / тармақтар |
| ГКП на ПХВ | ШЖҚ МКК |
| ССМП | ЖМЖС (Жедел медициналық жәрдем станциясы) |
| ПМСП | МСАК (медициналық-санитариялық алғашқы көмек) |
| ОСМС / ИПН / ОПВ | МӘМС / ЖТС / МЗЖ |
| СМЭ | СМС (сот-медициналық сараптама) |
| БИН / ГРНЗ / Vin-код | БСН / МТН / Vin-коды |

Негізгі заң терминдерінің баламалары ҚР Қылмыстық кодексі мен
Қылмыстық-процестік кодексінің ресми қазақ тіліндегі мәтіндеріне сәйкес
таңдалды (мысалы: «присвоение» → «иеленіп алу», «хищение» → «ұрлау»,
«пособничество» → «сыбайластық», «в особо крупном размере» → «аса ірі
мөлшерде», «лицо, приравненное к лицам, уполномоченным на выполнение
государственных функций» → «мемлекеттік функцияларды орындауға уәкілеттік
берілген адамдарға теңестірілген адам»).

## Тегі мен аты-жөнін жазу тәртібі

Қазақ тіліндегі ресми іс қағаздарының тәртібіне сәйкес аты-жөні алдымен
(есімі мен әкесінің аты не олардың бас әріптері), содан кейін тегі жазылады,
ал қажетті септік жалғауы **тегіне** жалғанады. Мысалы:

- `Оразбаев М.Б.` → `М.Б. Оразбаев`
- `Оразбаев М.Б.-ның` → `М.Б. Оразбаевтың`
- `Әбдіров А.Б.-ға` → `А.Б. Әбдіровқа`
- `Балабеков А.Т.-мен` → `А.Т. Балабековпен`
- `Оразбаев Мурат Бекайдарович` → `Мурат Бекайдарович Оразбаев`

> **Ескерту.** Аудармадағы адамдардың тегі мен есімдері түпнұсқадағы (ресми
> сәйкестендіру құжаттарындағы) жазылуымен сақталды.
