**USD-счёт** — транзитный (остатки 0 → 0): валюта покупается за тенге и сразу
уходит иностранным перевозчикам (MEGA STOCK, Таиланд; Altyn Trans, Узбекистан).
Эти выплаты (**202,5 млн ₸ / $425 703**) — реальная себестоимость международного
транзита; ранее по одним тенговым счетам они были видны лишь как «покупка валюты»
и не попадали в P&L, из-за чего валовая маржа была завышена (51% → фактически ~29%).

Итоговый файл: **`WayStar_Управленческая_отчетность_15.06-15.07.2026.xlsx`** — 8 листов:

1. **Резюме** — ключевые показатели P&L и свод движения денег.
2. **Аналитика** — коэффициенты рентабельности, риск концентрации клиентов (топ-1/3/5,
   HHI), рентабельность сегментов Аренда/ТЭО, выводы и риски + **5 графиков**
   (топ-10 клиентов, структура выручки, каскад P&L, структура расходов, денежный поток).
3. **P&L (кассовый)** — отчёт о прибылях и убытках (кассовый метод).
4. **P&L по клиентам** — выручка по каждому клиенту с разбивкой на **Аренду** и **ТЭО**,
   распределённые прямые расходы (аренда / ТЭО) и накладные, валовая и чистая прибыль.
5. **ДДС (Cash Flow)** — движение денежных средств прямым методом со сверкой по банкам.
6. **Выручка по клиентам** — детально, 28 клиентов.
7. **Расходы** — по категориям и топ-20 поставщиков.
8. **Реестр операций** — все 441 операция с классификацией (с автофильтром) —
   **источник данных**: все показатели на других листах построены **формулами
   `SUMIFS`/`COUNTIFS`** по этому реестру, поэтому пересчитываются автоматически
   и полностью прослеживаются до конкретных операций.

Направление (Аренда / ТЭО) размечено для операций выручки и себестоимости:
**Аренда** — сдача/субаренда вагонов и цистерн; **ТЭО** — экспедирование, ж/д тариф,
предоставление подвижного состава, оперирование, дислокация.

## Методология и классификация

Каждая из 441 операции классифицирована по коду назначения платежа (КНП)
и назначению платежа в один из потоков:

- **REVENUE** — поступления от клиентов за транспортно-логистические услуги
  (ТЭО, предоставление вагонов/цистерн, ж/д тариф).
- **COGS** — оплата перевозчикам (КТЖ, ҚАЗТЕМІРТРАНС), субподряд, аренда/ремонт вагонов,
  **иностранный транзит через USD-счёт** (Таиланд, Узбекистан).
- **OPEX** — зарплата, аренда офиса, командировочные, банковские услуги, связь, ТМЦ, страхование.
- **TAX** — налоги и социальные платежи (КГД/УГД, Госкорпорация «Правительство для граждан»).
- **FIN_INCOME / FIN_COST** — проценты по депозитам / проценты и пени по кредитам.
- **FINANCING** — получение и погашение займов, фин. помощь.
- **TREASURY** — размещение/снятие депозитов (исключены из P&L).
- **INTERNAL** — переводы между собственными счетами + конвертация валюты KZT↔USD
  (элиминированы из P&L, показаны в ДДС).

### Важные оговорки

- Отчётность **кассовая**: «выручка» = деньги, поступившие за период; «расходы» =
  фактически уплаченные суммы. Не отражает начисления, дебиторскую/кредиторскую
  задолженность, амортизацию, НДС к зачёту/уплате.
- В **P&L по клиентам** выручка — фактическая по каждому клиенту, а себестоимость
  и косвенные расходы **распределены пропорционально доле в выручке** — в банковских
  выписках нет привязки платежей поставщикам к конкретному клиенту, поэтому маржа
  по клиенту носит оценочный характер.
- Валовый оборот по счетам (~4,6 млрд ₸) в основном состоит из казначейских движений
  (депозиты 2,37 млрд в каждую сторону) и переводов между своими счетами —
  они исключены из P&L и показаны в ДДС отдельными разделами.
- ~100,4 млн ₸ переведено на прочий собственный счёт компании (КЛС), а ~55,8 млн ₸
  конвертации ушло на другой валютный счёт — выписки по ним не предоставлены;
  отражено в разделе «Внутренние переводы и конвертация» ДДС.

## Бюджет на 2-е полугодие 2026 (H2)

Файл **`WayStar_Бюджет_H2_2026.xlsx`** — помесячный бюджет (июль–декабрь 2026),
построенный от факта 1 месяца как run-rate. Полностью **на формулах** от листа
редактируемых предпосылок (жёлтые ячейки). 5 листов:

1. **Сценарии** — Консервативный / Базовый / Оптимистичный + графики (выручка/EBITDA, остаток денег).
2. **Бюджет P&L** — помесячный отчёт о прибылях с маржами.
3. **Бюджет ДДС** — помесячное движение денег с переносом остатка и свободным потоком.
4. **Предпосылки** — драйверы: база выручки по сегментам, нормализация, рост, сезонность,
   ставки COGS, OPEX, налоги, финансы, начальный остаток.
5. **База (факт)** — месячный run-rate из отчётности (для прослеживаемости).

### Ключевые предпосылки и оговорки
- **Нормализация 85%** — база месяца содержит крупные авансы QAZAQ-ASTYQ (ТЭО «предоставление
  цистерн» 200 + 160 млн ₸), которые могут покрывать несколько месяцев; run-rate ×6 без
  хайрката завышал бы выручку. Драйвер редактируемый — калибруйте по договорам/факту.
- **Риск концентрации** — QAZAQ-ASTYQ ≈ 62% выручки; сценарии моделируют его снижение через
  нормализацию.
- **Налоги** заложены по кассовой ставке факта (~1,5% выручки: payroll+соц.+КПН за нерезидента).
  Если станет платиться КПН (20% с прибыли) без льготы — налог будет существенно выше; поднимите
  драйвер «Налоги, % от выручки».
- Свободный денежный поток (~890 млн ₸ за H2) при повторении показателей стоит размещать
  на депозиты/инвестиции — как и в факт-периоде.
