# ТОО «WayStar Group» — Система мотивации 75/25 и показатели эффективности

Приложения к приказу о введении структуры оплаты **«75% постоянная + 25% переменная»**
(ввод с 01.01.2026). Встроено в структуру и терминологию исходных материалов компании
(приказ + Матрица 75-25 и KPI-форма).

## Согласовано с приказом

- Юрлицо: **ТОО «WayStar Group»**, ввод с **01.01.2026**, начисление переменной — **ежемесячно**.
- Переменная — **от 0% до 100% лимита (25%)** в зависимости от выполнения показателей (приказ п.4.3);
  премия **не превышает лимит** — перерасхода фонда нет.
- Стоп-факторы (дисциплина, происшествия, качество/сроки) — приказ п.4.4.
- Контроль — менеджер по персоналу Байльденова Ш. (приказ п.8).

## Суть модели

- Действующий доход = **75% оклад + 25% лимит премии**. При выполнении на 100% зарплата не меняется;
  недовыполнение → потеря части переменной. 25% держат в тонусе.
- **Передовая линия** (10 из 13): личная/командная **цель по валовой/чистой прибыли**,
  правило «валовая прибыль ≥ K× собственной стоимости».
- **Поддержка** (персонал, юрист): ≈25% переменной — на чистой прибыли компании.
- Показатели — под транспортную логистику: маржа на рейс, сроки доставки, себестоимость на
  тонну/км, загрузка и порожний пробег, сохранность груза, безопасность, собираемость оплаты.

## Формула

```
Премия = Лимит (25% × Целевой доход) × Итоговое выполнение × Стоп-фактор   (не выше лимита)
Итого  = Оклад (75%) + Премия
```

## Матрица (структура листа — как в исходном файле компании)

Столбцы: Подразделение · Должность · ФИО · Табельный № · Целевой доход (100%) · Оклад (75%) ·
Лимит премии (25%) · Дата начала · Примечание · Факт KPI, % · Начисленная премия · Итого.
«Факт KPI, %» подтягивается с листа «Показатели (детально)», где вводится выполнение по каждому
показателю (жёлтые ячейки); зелёные строки — цель по прибыли.

> Целевой доход (100%) = действующий оклад начисленный. Коэффициент K, пороги, реальные табельные
> номера и распределение ролей Президент/Генеральный директор — уточняются перед подписанием.
