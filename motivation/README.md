# Waystar Group — Система мотивации и KPI (модель 75/25)

Пакет для совета директоров: перевод оплаты труда на модель
**«75% постоянная часть + 25% переменная часть»** с привязкой переменной к прибыли.

## Суть модели

- Действующая ЗП делится: **75% фикс (гарантия) + 25% переменная (за результат)**. Переменная
  **вырезается** из текущей оплаты, не добавляется сверху → при выполнении на 100% ФОТ не растёт.
  Эти 25% «держат штат в тонусе».
- У каждого **фронтовика** (10 из 13 — топ-менеджмент, опер. директор, нач. логистики, логисты,
  менеджер по закрытию) — личная/командная **цель по валовой/чистой прибыли**, к ней привязана
  переменная. Якорь: **валовая прибыль ≥ K× собственной стоимости (ФОТ)**, K задаётся из P&L.
- **Бэк-офис** (HR, HR-менеджер, юрист) держит ≈25% переменной на чистой прибыли компании —
  чтобы весь штат тянул в одну сторону.

## Формула

```
Переменная к выплате = (25% × Оклад) × %KPI × Модификатор компании × Гейт   (кап 150% target)
Итого к выплате       = 75% × Оклад + Переменная к выплате
```

- **Под риском:** 25% оклада ≈ 4,96 млн ₸/мес (≈ 59,5 млн ₸/год).
- При 100% KPI и модификаторе 1,0 «Итого» = текущей ЗП (ФОТ без изменений).
- Максимум (stretch 150% переменной) → до +12,5% к окладу, только при перевыполнении (из прибыли).

## Калькулятор

- **Лист «Детализация KPI»** — вводите достижение по каждому KPI (жёлтые, 0–150%); зелёные строки —
  профит-цель. Итоговый %KPI = Σ(вес × достижение).
- **Лист «Калькулятор»** — фикс 75%, переменная target 25%, переменная к выплате, ИТОГО и Δ к текущему.
  Вводимые: **Модификатор компании** (F4, по чистой прибыли) и **Гейт** по строке.

> Коэффициент K профит-целей, пороги KPI, наименование юрлица и распределение ролей Президент/CEO —
> уточняются перед подписанием. Значения ФОТ — по управленческой ведомости, сверяются с бухгалтерией.
