# Waystar Group — Система мотивации и KPI

Пакет для совета директоров: перевод оплаты труда с «100% оклад» на модель
**«фиксированная часть (оклад) + переменная часть (премия по KPI)»**, привязанную
к результатам компании.

## Файлы

| Файл | Что это |
|------|---------|
| `Waystar_KPI_motivation_system.docx` | Основной документ: оценка ФОТ → методология → KPI-карты по всем 13 сотрудникам → положение о премировании → **проект приказа** |
| `Waystar_KPI_premium_calculator.xlsx` | Рабочий калькулятор премий (2 листа: «Калькулятор» + «Детализация KPI») |
| `build_docx.py` / `build_xlsx.py` | Скрипты генерации (воспроизводимость) |

## Что внутри документа

1. **Оценка ФОТ.** Месячный ФОТ (со всеми налогами) ≈ 22,28 млн ₸ (≈ 267,4 млн ₸/год),
   налоговая нагрузка 27,5%. Выводы: «тяжёлый верх» (топ-4 = 68% ФОТ), дублирование
   ролей Президент/CEO/Опер. директор, отсутствие грейдов (одна должность 150 000–800 000 ₸),
   100% фикс / 0% переменной.
2. **Методология.** Формула `Премия = Оклад × Целевой коэф. × %KPI × Модификатор компании × Гейт`;
   грейды A–E с целевой переменной 15–40%; каскад весов Компания/Функция/Индивид; каденс и Комитет по KPI.
3. **KPI-карты** для каждого из 13 сотрудников (3–5 KPI, веса, порог/цель/stretch, источник факта).
4. **Положение о премировании.** Шкала достижений, стоп-факторы (гейты), пример расчёта,
   самофинансирование фонда (gain-sharing из EBITDA).
5. **Проект приказа** о внедрении.

## Калькулятор (`.xlsx`)

- **Лист «Детализация KPI»** — вводите фактическое достижение по каждому KPI (жёлтые ячейки, 0–150%);
  итоговый %KPI по сотруднику считается как Σ(вес × достижение).
- **Лист «Калькулятор»** — премия по каждому сотруднику и совокупный фонд.
  Вводимые ячейки (жёлтые): **Модификатор компании** (E4) и **Гейт** по строке.
- Целевой фонд при 100% достижении и модификаторе 1,0 ≈ **84 млн ₸/год** (≈35% годового оклада);
  ≈59% фонда — 2 топ-роли, их переменную рекомендуется полностью гейтить EBITDA.

> Числовые пороги KPI — ориентировочные, калибруются владельцами функций перед утверждением.
> Наименование юрлица, реквизиты и распределение ролей Президент/CEO — уточнить перед подписанием.
