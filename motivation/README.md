# Waystar Group — Система мотивации и показателей эффективности (модель 75/25)

Пакет для совета директоров: перевод оплаты труда на модель
**«75% постоянная часть + 25% переменная часть»** с привязкой переменной к прибыли —
как это устроено в сильных транспортно-логистических компаниях.

## Суть модели

- Действующая зарплата делится: **75% постоянная (гарантия) + 25% переменная (за результат)**.
  Переменная **выделяется** из текущей оплаты, не добавляется сверху → при выполнении на 100%
  фонд не растёт. Эти 25% держат людей в тонусе.
- Каждый рейс и каждый клиент — источник прибыли. У сотрудников **передовой линии** (10 из 13 —
  руководство, операционный директор, начальник логистики, менеджеры по логистике, менеджер по
  закрытию) — личная/командная **цель по валовой/чистой прибыли**. Правило: **валовая прибыль
  не ниже K× собственной стоимости (фонда оплаты)**, K настраивается по отчётности.
- **Поддержка** (отдел персонала, менеджер по персоналу, юрист) держит ≈25% переменной на
  чистой прибыли компании — чтобы весь коллектив тянул в одну сторону.

## Показатели (как в транспортной логистике)

- Валовая маржа (прибыль) по своим перевозкам и клиентам
- Соблюдение сроков доставки (в срок и в полном объёме)
- Себестоимость перевозки на рейс / тонну / километр
- Загрузка транспорта и порожний пробег
- Сохранность груза и уровень претензий
- Безопасность: происшествия, охрана труда
- Собираемость оплаты от клиентов

## Формула

```
Переменная к выплате = (25% × Оклад) × Выполнение × Коэффициент компании × Стоп-фактор   (предел 150%)
Итого к выплате       = 75% × Оклад + Переменная к выплате
```

- **Под результатом:** 25% оклада ≈ 4,96 млн ₸/мес (≈ 59,5 млн ₸/год).
- При выполнении на 100% и коэффициенте 1,0 «Итого» = текущей зарплате (фонд без изменений).
- Максимум (супер-цель 150% переменной) → до +12,5% к окладу, только при перевыполнении (из прибыли).

## Калькулятор

- **Лист «Показатели»** — вводите выполнение по каждому показателю (жёлтые, 0–150%); зелёные строки —
  цель по прибыли. Итоговое выполнение = сумма(вес × выполнение).
- **Лист «Расчёт»** — постоянная 75%, переменная целевая 25%, переменная к выплате, ИТОГО и разница
  к текущему. Вводимые ячейки: **Коэффициент компании** (F4, по чистой прибыли) и **Стоп-фактор** по строке.

> Коэффициент K, пороги показателей, наименование юридического лица и разграничение ролей
> Президент/Генеральный директор — уточняются перед подписанием. Значения фонда — по управленческой
> ведомости, сверяются с бухгалтерией.
