# ТОО «WayStar Group» — Система управления компанией

Операционная модель: перевод управления с «ручного режима собственника» на институты, чтобы
компания работала **без собственника в ежедневном контуре**. Дополняет систему мотивации 75/25
(папка выше).

## Что внутри (`WayStar_Система_управления.docx`)

1. **Три контура управления** — стратегический (собственник), управленческий (ген. директор),
   операционный (логистика). Цель — поднять собственника в стратегический.
2. **Роли и права решений** — разграничение Президент/Генеральный/Операционный/Финансовый,
   матрица прав решений (У/П/С/И) по 12 ключевым вопросам, лимиты полномочий по расходам.
3. **Оргструктура** — схема подчинённости, норма управляемости, назначение владельца выручки.
4. **Управленческий ритм** — календарь встреч (ежедневно/еженедельно/ежемесячно/квартал/год)
   с повесткой, участниками и результатом.
5. **Панель показателей** — единый дашборд со «светофором» и владельцами по каждому показателю.
6. **Каскад целей** — год → квартал → месяц → неделя.
7. **Регламенты** — минимальный набор для перевозчика (заявка, диспетчеризация, себестоимость
   рейса, претензии, счёт/оплата, наём, эскалация).
8. **Люди и преемственность** — встречи один на один, грейды логистов, дублёры ключевых ролей.
9. **Выход собственника из операционки** — 3 фазы по 30 дней.
10. **Дорожная карта внедрения (90 дней)**.

## Как связано с мотивацией

- Система мотивации 75/25 отвечает «за что платим» (показатели и премия).
- Система управления отвечает «как управляем» (роли, ритм, цифры, регламенты).
- Общий узел — **панель показателей** и **Комитет по показателям**.

## Воспроизведение

```bash
pip install python-docx
python3 management/build_docx.py
```

> Лимиты полномочий, состав встреч и пороги показателей — настраиваются под компанию перед утверждением.
