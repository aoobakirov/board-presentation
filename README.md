## Источники данных (актуализация на 30.06.2026)
- **IFA** (International Fertilizer Association) — Medium-Term Fertilizer Outlook 2025–2029:
  мировое потребление ≈204 млн т (2024, рекорд), рост 1–2%/год до ≈224 млн т к 2029;
  структура спроса N≈56% / P≈23% / K≈21%.
- **World Bank / отраслевые сводки** — цены 06.2026: карбамид ≈$700/т, аммофос (DAP) ≈$720/т
  (рост на фоне перебоев через Ормузский пролив; ослабление ожидается в 2027).
- **БНС РК / EnergyProm / ElDala** — рынок РК 2025: продажи ≈1,3 млн т (+19% г/г),
  импорт 552→700 тыс т (2023–2025), самообеспеченность по азоту 43,6% (фосфор 98,5%),
  структура импорта Россия 73% / Узбекистан 11%.
- **FAO / World Bank** — внесение удобрений: РК ≈4–5 кг/га (норма 80–100), Узбекистан ≈150,
  Бразилия ≈344 кг/га.
- Экономика ОМУ, цены конкурентов и эффективность 1:3 — из маркетингового источника
  (`source/market_analysis_source.pptx`).
