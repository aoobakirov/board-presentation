# KazBioFert — маркетинговый обзор (современный дизайн)

Модернизированная версия маркетингового дека KazBioFert
(«Краткий маркетинговый обзор рынка удобрений», 9 → 11 слайдов).

**Итоговый файл:** [`../KazBioFert_Marketing_Modern.pptx`](../KazBioFert_Marketing_Modern.pptx)
**Исходник:** [`../source/KazBioFert_marketing_overview_ORIGINAL.pptx`](../source/KazBioFert_marketing_overview_ORIGINAL.pptx)

## Что сделано

Содержание исходника сохранено полностью и приведено к единому современному
стилю: тёмно-зелёная палитра (биогаз + агро), карточки с мягкой тенью, иконки
в кружках, крупные стат-выноски, единый футер. Плотные слайды разведены для
воздуха, титул и финал — на тёмном фоне («сэндвич»).

| # | Слайд |
|---|-------|
| 1 | Титул (hero-панель) |
| 2 | Виды удобрений и элементы питания (N·P·K, 4 типа, ОМУ) |
| 3 | Биогазовый завод — площади, объём, компост (3D-визуализация) |
| 4 | Схема производства ОМУ + эффективность 1:3 по FAO |
| 5 | Полевые опыты: кукуруза +19%, ячмень +25% (карты) |
| 6 | Яровой ячмень — таблица экономики (OneSoil / FieldView) |
| 7 | Исследования НПЦЗХ им. Бараева — пшеница, рекомендация |
| 8 | Продукция — ОМУ NPK 12-12-12 и NP 8-21 (составы) |
| 9 | Преимущества ОМУ (8 плиток) |
| 10 | Модели работы с дистрибьюторами (7 моделей, 3 категории) |
| 11 | Финал (KPI: 75 000 т · +20% · 1:3) |

## Пайплайн сборки

```bash
npm install pptxgenjs react-icons react react-dom sharp   # зависимости
node gen_icons.js        # рендер иконок react-icons → assets/icons/*.png
python3 prep_images.py   # градиенты, hero-панель, скруглённые фото (нужны сырьё из assets/)
node emit_pptx.js        # → ../KazBioFert_Marketing_Modern.pptx
```

Слои визуального контроля:

```bash
node emit_html.js        # тот же layout-код → preview.html (QA-превью)
```

`build_lib.js` — единая модель слайдов; её потребляют и `emit_pptx.js`
(pptxgenjs), и `emit_html.js` (HTML-превью для проверки вёрстки в браузере,
т.к. LibreOffice в среде недоступен).

`assets/` содержит производные изображения (градиенты, скруглённые фото,
иконки), которые потребляет сборка. Сырые фото/логотипы извлекаются из
исходного `.pptx` и обрабатываются `prep_images.py`.
